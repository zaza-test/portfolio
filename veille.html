01/04/2026

Fuite Claude Code utilisée comme leurre (Vidar infostealer)

Zscaler ThreatLabz révèle l'exploitation d'une fuite du code source de Claude Code (agent IA terminal d'Anthropic) pour diffuser l'infostealer Vidar v18.7 via de faux dépôts GitHub. Un package npm officiel mal packagé embarquait 513 000 lignes de TypeScript, massivement clonées. Des dépôts frauduleux « leaked-claude-code » référencés en tête de Google servent de vecteur : l'archive téléchargée déploie un dropper, Vidar et le proxy GhostSocks, permettant vol de mots de passe et cookies. Risque supply chain documenté : backdoors dans des forks populaires, hooks malveillants ou dépendances npm piégées.

02/04/2026

Vulnérabilité Claude Code – contournement des règles deny (Adversa AI)

Au-delà de 50 sous-commandes chaînées dans un pipeline shell, le moteur de permissions de Claude Code cesse d'appliquer les règles deny. Un dépôt malveillant avec un fichier CLAUDE.md piégé pousse l'agent à générer un pipeline de 50+ étapes légitimes en apparence, au sein duquel le payload d'exfiltration s'exécute en position 51+. Cette limite résulte d'un compromis performance/sécurité documenté par Anthropic : un parseur plus robuste existe dans le code mais n'est pas activé dans les builds publics.

05/2026

CVE-2026-9082 – Prise de contrôle via Drupal

Un exploit public cible l'endpoint /jsonapi de Drupal : injection SQL via une clé de tableau malveillante dans les filtres PostgreSQL, permettant une extraction aveugle de données et la récupération du compte administrateur (uid=1). Correctifs disponibles : Drupal 11.3.10, 11.2.12, 11.1.10, 10.6.9, 10.5.10, 10.4.10.

05/2026

CVE-2026-20182 – Contournement d'auth Cisco SD-WAN

Exploit public permettant de contourner l'authentification du plan de contrôle via DTLS/UDP 12346 en se présentant comme un équipement vHub. L'attaquant peut injecter une clé SSH dans authorized_keys de vmanage-admin et obtenir un accès persistant via NETCONF/SSH (port 830). Correctifs : Cisco Catalyst SD-WAN 20.9.9.1, 20.12.5.4, 20.15.5.2, 26.1.1.1 et autres branches.

05/2026

MiniPlasma – Élévation de privilèges Windows (0-day)

Exploit non référencé ciblant le pilote noyau Windows Cloud Files Mini Filter (cldflt.sys), lié à la CVE-2020-17103 supposément corrigée en 2020. Un utilisateur local standard peut obtenir des privilèges SYSTEM. Aucun correctif disponible à ce jour.

05/2026

CVE-2026-31635 – Élévation de privilèges noyau Linux

Exploit public ciblant le sous-système RxRPC/RxGK du noyau Linux : un utilisateur local peut obtenir les droits root. Correctifs disponibles via les commits a2567217ade9, beee051f259a et e2f1a80d8b1e selon la branche utilisée.

19/05/2026

CVE-2024-12802 – SonicWall VPN SSL exploité activement

ReliaQuest révèle l'exploitation entre février et mars 2026 d'une faille SonicWall (corrigée en janvier 2025) permettant de contourner le MFA pour les connexions au format UPN. Des environnements pourtant patchés ont été ciblés faute d'application complète des mesures de remédiation. Campagne attribuée à un groupe de ransomware.

23/04/2026

CVE-2026-32202 – Zero-click Windows Shell exploité par APT28

Akamai signale l'exploitation par le groupe russe APT28 d'une vulnérabilité zero-click dans Windows Shell, résultant d'un correctif incomplet de la CVE-2026-21510. Sans interaction utilisateur, un attaquant peut usurper l'identité d'un utilisateur réseau et accéder à des informations sensibles.

21/05/2026

CVE-2026-26980 – Ghost CMS exploité à grande échelle

XLab révèle l'exploitation massive d'une faille Ghost CMS (corrigée en février 2026) permettant l'accès non authentifié aux clés API d'administration. Plus de 700 domaines touchés (universités, blockchain, IA/SaaS, médias…). Les attaquants déploient des campagnes ClickFix pour maintenir une persistance sur les systèmes compromis.
